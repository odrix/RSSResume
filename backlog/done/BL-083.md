# BL-083 - Autre mode de connexion : magic-link
- **Catégorie** : web
- **Priorité** : 1
- **Description** : pouvoir se connecter avec un lien envoyé par email, à la place du
  mot de passe. Choix possible à la création du compte (email seul, sans mot de passe).
  Un mot de passe peut être ajouté ensuite depuis la page _Compte_ ; les deux méthodes
  fonctionnent alors. Le login propose toujours « recevoir un lien » à côté du mot de passe.
  - Jeton : 32 octets aléatoires, seul son hash est stocké en base ; valable 15 min,
    à usage unique ; une nouvelle demande invalide les précédents.
  - Le lien ouvre une page de confirmation avec un bouton (POST) : un simple GET ne
    consomme pas le jeton, pour résister aux préchargements des clients mail.
  - Le compte est créé à la première validation du lien (l'email est ainsi vérifié).
  - Même réponse que l'email existe ou non (pas d'énumération de comptes).
  - Limite : 5 demandes par heure et par email, et par IP.
  - Envoi de l'email par l'API Python ; la session est créée par le backend Svelte,
    comme pour le login par mot de passe.
  - Réglages de l'installation (`.env`) : SMTP, durée de validité du lien, URL publique
    du site. Sans SMTP configuré, le lien est écrit dans les logs (dev).
- **Bénéfice attendu** : faciliter la connexion et les premiers essais, tout en gardant
  un très bon niveau de sécurité.
- **Tests d'acceptation** :
  - [x] un email inconnu reçoit un lien ; sa validation crée le compte et ouvre la session ;
  - [x] un lien utilisé une fois, expiré ou remplacé par une demande plus récente est refusé ;
  - [x] ouvrir le lien (GET) sans cliquer sur le bouton ne consomme pas le jeton ;
  - [x] la réponse est identique pour un email connu et inconnu ;
  - [x] la 6e demande en une heure est refusée ;
  - [x] un compte sans mot de passe peut en définir un dans _Compte_, puis utiliser les deux ;
  - [x] le login par mot de passe existant est inchangé ;
  - [x] `.env.example` documente les réglages (ORIGIN déjà présent, durée codée en dur).
- **Réalisé le** : 2026-11-25
