# BL-022 — Exclure du pipeline les flux non résumables
- **Catégorie** : pipeline
- **Priorité** : 2
- **Description** : NoLimitSecu est un podcast sans transcription dans son RSS, « FreshRSS
  releases » un changelog : les envoyer au scoring coûte des tokens pour un résultat vide. Ajouter
  une liste d'exclusion **par flux** (pas par catégorie), appariée sur `Article.feed_title`,
  insensible à la casse. Les articles exclus ne sont ni notés ni résumés, mais restent marqués lus
  normalement. Le réglage est personnel : il se déclare dans le document de profil (`profil.py`),
  pas dans l'environnement. Cible initiale : NoLimitSecu et FreshRSS releases.
- **Bénéfice attendu** : moins de tokens de scoring chaque jour, sur des articles qui ne pouvaient
  rien donner.
- **Réalisé le** : 2026-11-23
- **Livraison** : branche `backlog/BL-022-flux-exclus`
- **Notes** : la clé est `flux_exclus`, une liste de titres de flux. L'appariement est une égalité
  (pas une sous-chaîne : « Go » n'exclut pas « Google ») qui ignore la casse **et** les accents,
  comme le catalogue. L'exclusion s'applique avant `--limit` ; CERT-FR n'est pas filtré (aucun appel
  au modèle). Hors du texte : `annuaire_sqlite.py` devait connaître la clé, sans quoi la base de
  production la supprimait en silence ; une catégorie dont tous les articles viennent de flux
  exclus le dit (« … tous de flux exclus du résumé ») au lieu d'annoncer « aucun nouvel article ».
  Un article exclu figure au journal avec `origine_note: "aucune"`, comme un article au-delà de
  `--limit` : `parametres.flux_exclus` en donne la raison, une origine distincte n'a pas été jugée
  utile. La cible initiale n'est pas déclarée : c'est le document personnel de l'utilisateur. Le
  site efface encore la clé à chaque enregistrement de « Mon profil » : c'est BL-066. Le défaut
  trouvé en chemin sur les axes de la tournée est BL-065.
- **Tests d'acceptation** :
  - [x] un article d'un flux exclu n'atteint ni le scoring ni le résumé ;
  - [x] il est quand même marqué lu ;
  - [x] l'appariement ignore la casse et porte sur le titre du flux, pas sur la catégorie ;
  - [x] liste absente ou vide : comportement inchangé ;
  - [x] README et FONCTIONNEMENT documentent la clé du profil.
