# BL-088 - Lecteur audio persistant entre les navigations
- **Catégorie** : web
- **Priorité** : 2
- **Description** : naviguer pendant l'écoute coupe le son : le lecteur vit dans la page.
  Remonter le lecteur dans le layout SvelteKit (composant global piloté par un store), pour que
  la lecture continue quand on change de page. Selon le style de la page visitée, le lecteur
  se déplace de sa position de page vers un lecteur réduit persistant (mini-lecteur en bas
  d'écran : titre de la journée, progression, lecture / pause, reprise de la version pleine).
  Un seul audio à la fois : lancer une journée remplace la précédente.
- **Bénéfice attendu** : on peut lire la suite du site en continuant d'écouter, comme un
  véritable lecteur.
- **Tests d'acceptation** :
  - [x] la lecture survit à une navigation entre deux pages du site, sans saut ni reprise au début ;
  - [x] le mini-lecteur persistant affiche la journée en cours, la progression et les commandes de base ;
  - [x] lancer un autre audio arrête le premier ;
  - [x] les pages sans déclencheur audio n'affichent pas de lecteur vide ;
  - [x] `npm run check` et `npm test` verts.
- **Réalisé le** : 2026-11-26
- **Livraison** : branche backlog/BL-088-lecteur-persistant
- **Notes** : « selon le style de la page visitée » lu comme : selon que la page pose ou non
  un `LecteurPlein` pour la piste ; sinon, mini-lecteur. Le lecteur est fourni par le contexte
  Svelte, pas par un état de module, qui serait partagé entre les requêtes SSR. La survie à une
  navigation est prouvée par les tests unitaires du lecteur (ancrage / désancrage sans effet sur
  l'élément audio) ; elle reste à constater une fois dans un vrai navigateur. Écart au plan :
  `vite.config.ts` découpé en deux projets vitest (« serveur » et « runes », ce dernier avec
  `environnement-runes.ts`, sans dépendance nouvelle) pour faire tourner de vrais `$effect` en
  test, c'est ce qui manquait pour attraper une boucle d'effet relevée en revue. Le marquage
  « écouté » de BL-094 se branche sur `surEcouteTerminee` à la fusion des deux branches. Suite
  ouverte : BL-097.
