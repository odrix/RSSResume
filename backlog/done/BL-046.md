# BL-046 - Page profil guidée
- **Catégorie** : web
- **Priorité** : 2
- **Dépend de** : BL-038, BL-041
- **Description** : la page n'offre qu'un texte libre sans exemple, et la stack se présente par
  « CERT-FR » et « ex. Keycloak / RH-SSO ». Ajouter : les catégories du catalogue à cocher, avec leur
  description ; les axes modifiables ; le régime de sécurité expliqué en une ligne par valeur ; une
  aide structurée pour le texte (mon métier, ce que je veux suivre, ce qui ne m'intéresse pas) avec
  l'exemple du gabarit ; « repartir d'un gabarit » ; une stack présentée comme facultative
  (« si vous exploitez des serveurs ou des logiciels ») avec des exemples neutres.
- **Bénéfice attendu** : chacun règle son digest sans connaître le fonctionnement interne.
- **Réalisé le** : 2026-11-23
- **Livraison** : branche `backlog/BL-046-page-profil-guidee`
- **Notes** : le catalogue n'était pas exposé au site : nouvelle route
  `GET /api/v1/profils/{username}/categories` (publiques et privées de soi, sans propriétaires).
  Les erreurs de validation nomment leur champ (`ChampInvalide`, corps `{"erreur", "champ"}`), ce
  qui remplace la regex du site. Toutes les cases cochées = clé `categories` omise (décision de
  l'utilisateur : le profil suit aussi les catégories futures, un changement de prénom ne fige pas
  l'abonnement). Hors du texte, trouvé en chemin : `AnnuaireSqlite.modifier()` ne validait pas les
  catégories contre le catalogue ; il le fait désormais, mais ne refuse que les catégories
  **ajoutées**, une catégorie suivie puis retirée du catalogue reste tolérée (la tournée la
  refiltre), ce qui évite de bloquer la page ou `Destinataires.confirmer`. Un catalogue illisible
  en base répond 500 journalisé (`CatalogueIllisible`), jamais une 422 montrée à la personne.
  Accepté : le catalogue est lu avant la transaction d'écriture de `modifier()`, une course avec
  `remplacer_catalogue` peut valider contre l'ancien catalogue (la tournée refiltre). Changer ses
  axes depuis la page renote les articles au passage suivant ; la page ne le dit pas. `flux_exclus`
  est toujours effacé à l'enregistrement : c'est BL-066. Suites : BL-069 (email de bienvenue),
  BL-070 (trame des gabarits).
