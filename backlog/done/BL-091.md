# BL-091 - Profil : catégories et stacks en listes repliées avec résumé ellipsé
- **Catégorie** : web
- **Priorité** : 3
- **Dépend de** : BL-090
- **Description** : dans le profil, les listes longues (catégories cochables, stacks
  surveillées) occupent toute la place. Les rendre repliables (collapsables), repliées par
  défaut pour les stacks surveillées. En mode replié, le résumé montre uniquement les éléments
  cochés, sur une seule ligne maximum : ellipsis (…) quand ça dépasse, sans jamais casser la
  mise en page. Un dépliage révèle la liste complète pour cocher / décocher.
- **Bénéfice attendu** : un profil compact où l'on voit d'un coup d'œil ce qui est actif, et la
  liste complète seulement quand on en a besoin.
- **Tests d'acceptation** :
  - [ ] catégories et stacks sont repliables ; les stacks sont repliées par défaut ;
  - [ ] en replié, seuls les éléments cochés sont résumés, sur une ligne, ellipsés au-delà ;
  - [ ] cocher / décocher après dépliage met à jour le résumé replié ;
  - [ ] `npm run check` et `npm test` verts.
