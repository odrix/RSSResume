# BL-078 - Page d'accueil : un exemple de digest et la mention bêta
- **Catégorie** : web
- **Priorité** : 2
- **Description** : la page d'accueil tient en trois paragraphes ; un visiteur ne sait pas ce qu'il
  recevra avant le lendemain matin de son inscription. Y montrer un exemple : un extrait de lettre
  et un court extrait audio d'une journée choisie par l'exploitant, tirée d'une catégorie publique
  et figée dans `web/static/` (jamais rien d'une catégorie privée). Dire aussi que le service est en
  bêta, ce qu'on reçoit et à quelle heure, et que les retours (BL-071) décident de la suite.
- **Bénéfice attendu** : une visite qui se transforme en inscription, le jour où la communication
  commence.
- **Tests d'acceptation** :
  - [x] la page d'accueil, accessible sans connexion, montre l'extrait de lettre et un lecteur audio ;
  - [x] la mention bêta est visible sans défiler sur mobile ;
  - [x] l'exemple ne dépend ni de l'API ni d'une session ;
  - [x] `npm run check` et `npm test` verts.
- **Réalisé le** : 2026-11-27
- **Livraison** : branche backlog/BL-078-accueil-exemple-beta
- **Notes** : L'exemple livré est une démonstration (lettre.txt neutre, extrait.mp3 silencieux de 12 s) : l'exploitant remplacera par un vrai extrait d'une catégorie publique. Le load Essaie `static/exemple/` puis `build/client/exemple/` : en production Docker, seul `build/` est copié dans l'image finale. Rafraîchissement automatique de l'exemple depuis une vraie journée : réservé en BL-101, non fait ici.
