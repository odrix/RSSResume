# BL-093 - Profil : une seule adresse de réception
- **Catégorie** : web
- **Priorité** : 3
- **Dépend de** : BL-090
- **Description** : tant que les ouvertures n'arrivent pas, cacher la gestion de plusieurs
  adresses de réception : une seule adresse par compte, dérivée de l'email du compte, sans
  champ d'édition ni liste d'adresses dans le profil. Renommer les libellés au singulier.
  Ne rien supprimer côté données : la notion d'adresses multiples reste dans le modèle pour
  une réintroduction future, seul l'affichage et l'édition multi sont masqués.
- **Bénéfice attendu** : un profil plus simple, sans réglage inutile pour un compte à une adresse.
- **Tests d'acceptation** :
  - [ ] le profil n'affiche plus de gestion multi-adresses, uniquement l'adresse du compte ;
  - [ ] la lettre part toujours vers l'adresse unique, comme avant ;
  - [ ] le modèle de données garde la notion d'adresses multiples sans régression pour l'envoi ;
  - [ ] `npm run check`, `npm test` et la suite unittest verte.
