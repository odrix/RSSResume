# BL-071 - Canal de retour : « utile / pas utile » sur chaque journée
- **Catégorie** : web, pipeline (`newsletter.py`) pour les liens de la lettre
- **Priorité** : 1
- **Dépend de** : BL-044
- **Description** : la bêta n'a de sens que si les retours arrivent, et rien ne les recueille
  aujourd'hui. Au pied de la lettre, deux liens signés « utile » et « pas utile » pour la journée,
  sur la même mécanique que le lien de désabonnement de BL-044 (sans connexion). Ils mènent à une
  page du site qui enregistre le vote et propose un commentaire libre, facultatif. Les mêmes
  boutons figurent sur la page des résumés pour qui est connecté. Les retours sont rangés par
  profil et par journée, et listés dans `/admin`, les plus récents d'abord. C'est le noyau de
  BL-034, sans les amendements du profil, qui attendront de voir ce que disent les retours.
- **Bénéfice attendu** : savoir, journée par journée, si le digest sert à ceux qui le reçoivent, et
  pourquoi pas quand il ne sert pas.
- **Réalisé le** : 2026-11-23
- **Livraison** : branche `backlog/BL-071-retours-utile`
- **Tests d'acceptation** :
  - [x] un lien de vote ne vaut que pour son profil et sa journée, et un lien altéré est refusé ;
  - [x] un second vote sur la même journée remplace le premier ;
  - [x] le commentaire est borné en longueur et rendu échappé dans `/admin` ;
  - [x] seules les personnes admin voient la liste des retours ;
  - [x] `--send-only` rend la même lettre, liens de vote compris ;
  - [x] suites Python et web vertes.
