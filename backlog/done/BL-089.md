# BL-089 - Ordre des catégories : numérique avant alphabétique
- **Catégorie** : web, avec un point côté `newsletter.py`
- **Priorité** : 2
- **Description** : les catégories préfixées par un numéro se trient alphabétiquement
  (« 11 » avant « 2 ») à l'écran comme dans l'email. Trier numériquement le préfixe, puis
  alphabétiquement (tri naturel : 2 avant 11) partout où les catégories s'affichent ; le tri de
  FreshRSS lui-même n'est pas touché. Alternative acceptable si elle est retenue à l'implémentation :
  un classement explicite et la suppression de l'affichage des chiffres côté site et email.
  Trancher entre tri naturel et classement en dur : un seul comportement, même choix sur le
  site et dans la lettre.
- **Bénéfice attendu** : des catégories dans un ordre lisible, qui suit leur numérotation.
- **Tests d'acceptation** :
  - [x] sur le site, « 2 … » s'affiche avant « 11 … » ;
  - [x] dans l'email, les sections suivent le même ordre que sur le site ;
  - [x] les catégories sans préfixe numérique se classent après celles à préfixe, par ordre alphabétique ;
  - [x] `npm run check`, `npm test` et la suite unittest verte pour la comparaison d'ordre.
- **Réalisé le** : 2026-11-26
- **Livraison** : branche backlog/BL-089-tri-naturel
