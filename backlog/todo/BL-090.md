# BL-090 — Page profil allégée : un bouton, un popup
- **Catégorie** : web
- **Priorité** : 2
- **Description** : la page profil (391 lignes) empile tout en surface : reprendre à plat et la
  reconstruire sur un gabarit léger. Chaque finalement réglable (jeux de flux, stacks
  surveillées, adresses) se réduit à un simple bouton résumant son état actuel, qui ouvre un
  popup d'édition ; on revient à la page allégée à la fermeture. Aucune régression
  fonctionnelle : tout ce qui se règle aujourd'hui se règle encore, comme pour les rubriques
  détaillées dans BL-091 à BL-093.
- **Bénéfice attendu** : une page profil lisible d'un coup d'œil, où l'on voit l'état du profil
  sans être noyé par les réglages.
- **Tests d'acceptation** :
  - [ ] chaque rubrique s'affiche en bouton résumé, et son édition se fait dans un popup ;
  - [ ] tous les réglages existants restent possibles, l'enregistrement se comporte comme avant ;
  - [ ] les pages et tests existants de `profil/` sont adaptés (`page.test.ts`) ;
  - [ ] `npm run check` et `npm test` verts.
