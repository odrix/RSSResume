# BL-081 — Changer l'adresse du compte met à jour les destinataires du digest
- **Catégorie** : web
- **Priorité** : 3
- **Description** : depuis BL-043, « Mon compte » change l'adresse de connexion après un clic sur
  le lien reçu par la nouvelle adresse. Seul le compte du site change : le profil côté API garde
  sa liste `email`, si bien que l'ancienne adresse continue de recevoir le digest jusqu'à ce que
  la personne la retire elle-même dans « Mon profil », et que la nouvelle ne le reçoit pas tant
  qu'elle ne l'y ajoute pas. À la confirmation de la nouvelle adresse, remplacer l'ancienne par la
  nouvelle dans les destinataires du profil — si l'ancienne y figurait —, en laissant les autres
  adresses intactes. La nouvelle vient d'être prouvée par le lien : elle n'a pas à repasser par la
  file d'attente de `destinataires.ts`. Une API indisponible ne doit pas défaire le changement
  d'adresse du compte : la page dit alors que les destinataires sont à revoir dans « Mon profil ».
- **Bénéfice attendu** : une personne qui change d'adresse reçoit son digest à la nouvelle, et
  l'ancienne boîte — peut-être abandonnée ou réattribuée — cesse de le recevoir.
- **Tests d'acceptation** :
  - [ ] l'ancienne adresse, si elle était destinataire, est remplacée par la nouvelle dans le
        profil à la confirmation, et seulement à la confirmation ;
  - [ ] les autres destinataires du profil sont conservés, et une ancienne adresse absente de la
        liste n'y fait pas entrer la nouvelle ;
  - [ ] une API indisponible laisse le compte changé et le signale à la personne ;
  - [ ] `npm run check` et `npm test` verts.
