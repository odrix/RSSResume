# BL-087 — Animation de lecture pendant l'écoute
- **Catégorie** : web
- **Priorité** : 3
- **Description** : pendant qu'un audio joue, l'icône lecture reste figée. La remplacer par une
  animation de lecture (vagues ou barres animées) sur l'élément déclencheur, animée par l'état
  réel du lecteur (lecture, pause, fin), pas par un état local dupliqué. L'icône pause et
  l'arrêt restent clairement distingués de l'animation. Alternative accessible : ne pas porter
  l'information par la couleur ou le mouvement seul — l'état reste annoncé aux lecteurs d'écran.
- **Bénéfice attendu** : un retour visuel immédiat de ce qui joue, sans ambiguïté avec un bouton non démarré.
- **Tests d'acceptation** :
  - [ ] l'élément déclencheur affiche l'animation uniquement quand l'audio joue ;
  - [ ] pause et fin d'audio arrêtent l'animation, même en cas de navigation entre pages ;
  - [ ] l'état de lecture reste consultable par les lecteurs d'écran ;
  - [ ] `npm run check` et `npm test` verts.
