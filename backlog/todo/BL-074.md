# BL-074 — Suppression du compte par la personne
- **Catégorie** : web
- **Priorité** : 4
- **Description** : détaché de BL-043. Depuis « Mon profil », la personne supprime son compte :
  compte du site, profil via le `DELETE` de l'API déjà au contrat, et sorties `output/<id>/`, après
  une confirmation explicite. Le même chemin servira à l'admin (BL-049). D'ici là, la suppression
  se demande au contact de la page de confidentialité (BL-043).
- **Bénéfice attendu** : le droit à l'effacement exercé sans intervention de l'exploitant.
- **Tests d'acceptation** :
  - [ ] la suppression retire compte, profil et sorties, et la tournée suivante ne sert plus personne
        sous ce nom ;
  - [ ] elle demande une confirmation et n'est possible que pour son propre compte ;
  - [ ] `npm run check` et `npm test` verts, tests API en unittest pour la suppression des sorties.
