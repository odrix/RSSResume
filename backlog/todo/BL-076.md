# BL-076 - Éditer les flux exclus depuis « Mon profil »
- **Catégorie** : web
- **Priorité** : 4
- **Dépend de** : BL-066
- **Description** : détaché de BL-066. `flux_exclus` (BL-022) ne se règle que par l'API. Le rendre
  lisible et modifiable dans « Mon profil », comme une liste de titres de flux, de préférence choisis
  parmi les flux des catégories du profil plutôt que tapés à la main.
- **Bénéfice attendu** : écarter soi-même un flux bruyant, sans passer par l'exploitant.
- **Tests d'acceptation** :
  - [ ] `flux_exclus` se lit et se modifie depuis « Mon profil » ;
  - [ ] une liste vide retire la clé sans effacer les autres ;
  - [ ] suites Python et web vertes.
