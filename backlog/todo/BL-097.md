# BL-097 - Voter sur un résumé sans couper l'audio
- **Catégorie** : web
- **Priorité** : 3
- **Dépend de** : BL-088
- **Description** : depuis BL-088, l'audio continue d'une page à l'autre, mais aucun formulaire
  du site n'utilise `use:enhance` : envoyer un vote de `FormulaireRetour` recharge toute la page
  et coupe la lecture. C'est l'action la plus probable pendant une écoute. Améliorer ce
  formulaire (et ceux qu'on remplit en écoutant) avec `use:enhance`, en gardant le
  fonctionnement sans JavaScript. La déconnexion peut continuer à recharger la page.
- **Bénéfice attendu** : on peut noter un résumé sans perdre sa place dans l'écoute.
- **Tests d'acceptation** :
  - [ ] voter sur un résumé pendant la lecture ne coupe ni ne relance l'audio ;
  - [ ] le vote fonctionne toujours sans JavaScript ;
  - [ ] le retour du vote (confirmation, erreur) s'affiche sans rechargement ;
  - [ ] `npm run check` et `npm test` verts.
