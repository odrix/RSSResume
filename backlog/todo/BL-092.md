# BL-092 - Profil : rendre la rubrique résumé compréhensible
- **Catégorie** : web
- **Priorité** : 2
- **Dépend de** : BL-090
- **Description** : la rubrique « résumé » de la page profil n'est pas claire, même son
  auteur ne sait plus exactement comment elle fonctionne. La refaire : écrire en une phrase ce
  qu'elle montre, d'où viennent les lines (jour, mode, dernière édition), et en faire un
  bouton résumé au sens de BL-090 avec un popup explicite. Si l'état sous-jacent n'est pas
  nettoyable, le dire ici avant de coder ; ne pas déguiser un état confus en libellé flou.
- **Bénéfice attendu** : l'utilisateur comprend ce que la rubrique résume et comment la régler.
- **Tests d'acceptation** :
  - [ ] la rubrique affiche une description explicite de ce qu'elle résume ;
  - [ ] une modification faite dans le popup est reflétée immédiatement dans le résumé ;
  - [ ] `npm run check` et `npm test` verts.
