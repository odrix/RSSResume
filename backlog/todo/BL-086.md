# BL-086 — Charte graphique de l'email
- **Catégorie** : pipeline (`newsletter.py`)
- **Priorité** : 3
- **Description** : la lettre est envoyée en HTML brut sans identité visuelle cohérente avec le
  site. Définir une charte simple (logo, couleurs, typographie, pied de page) appliquée aux
  versions HTML et texte, cohérente avec le site. Contraintes email : gabarit en tableaux et
  styles en ligne, largeur fixe (~600 px), alternatives texte pour tout ce qui porte de
  l'information, rendu vérifié sur au moins un client sombre. La charte sert autant à la lettre
  quotidienne qu'aux emails transactionnels (magic-link BL-083, réinitialisation) : un gabarit
  partagé côté API.
- **Bénéfice attendu** : une lettre reconnaissable, moins propice aux indésirables, cohérente
  avec l'expérience du site.
- **Tests d'acceptation** :
  - [ ] les versions HTML des lettres et des emails transactionnels suivent le gabarit charté ;
  - [ ] styles en ligne, gabarit en tableaux, aucune ressource externe lourde (images servies en absolu ou évitées) ;
  - [ ] le mode texte garde toutes les informations et les liens ;
  - [ ] `--send-only` rend la même lettre que le passage du jour.
